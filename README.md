# Titanic Survival Analysis

## Project Overview

This project analyzes the famous Titanic dataset to identify survival patterns among passengers using Python data analysis and visualization libraries.

The analysis focuses on:

* Survival comparison by gender
* Passenger class impact on survival
* Age distribution and survival trends
* Data cleaning and preprocessing

---

## Objective

The main objective of this project is to:

* Practice Exploratory Data Analysis (EDA)
* Handle missing data
* Generate meaningful insights using visualization
* Improve analytical thinking using real-world data

---

## Tools & Technologies Used

* Python

## Dataset Information

The dataset contains passenger information such as:

* Passenger Class
* Gender
* Age
* Fare
* Embarkation Port
* Survival Status

Target column:

* `Survived`

  * 0 = Did Not Survive
  * 1 = Survived

---

## Analysis Performed

The project includes:

* Dataset inspection
* Missing value handling
* Duplicate removal
* Survival analysis by gender
* Survival analysis by passenger class
* Survival analysis by age group

---

## Visualizations Included

* Bar chart of survival by gender
* Bar chart of survival by passenger class
* Histogram of passenger ages
* Survival count comparison charts

---

## Key Insights

* Female passengers had a higher survival rate.
* First-class passengers had better survival chances.
* Younger passengers showed relatively better survival patterns.
* Most passengers belonged to the young adult age group.
